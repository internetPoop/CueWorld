# 実装プラン

## 1. 容器とオブジェクトの位置関係の変更
**目標**: `contain_effect` によって容器に入ったオブジェクトの位置 (`_obj_pos`など) を取得した際に、容器の位置が返るようにする。

### 実装手順
1. **マッピングの導入**:
   - `cueworld/base.py` の `BaseEnv` の初期化時・リセット時 (`reset` メソッド内) に self.all_objectsのバリューにあるオブジェクトクラスの属性contained_inをNoneにリセットします
2. **入れた際の位置の追跡 (`contain_effect`)**:
   - `contain_effect` メソッド内でオブジェクトが容器に追加された際、`target_obj.contained_in = container_obj.id` を登録する。
   - `[0, 0, -100]` へ退避する処理や `active_objects` からの削除はそのままで問題ない。
3. **取り出した際の追跡解除 (`remove_effect`)**:
   - オブジェクトが容器から取り出された際 (`remove_effect` が実装されている・または実装される場合)、`target_obj.contained_in = None`にする。
4. **位置の取得処理の変更 (`_obj_pos`)**:
   - `_obj_pos` メソッド内において、引数の `oid` が に対応するオブジェクトのcontained_inがNoneでなければ 、それが格納されている容器のIDを取得し、その容器の位置を求めて返すように変更する。

## 2. 容器判定用バウンディングボックスのサイズ最適化
**目標**: `_update_grasp` でオブジェクトを手放した際の容器入れ判定が、固定サイズ（1.0の立方体）になっているため、各オブジェクト固有の大きさに合わせた判定に変更する。

### 実装手順
1. **`items.py` のサイズ属性充実**:
   - `cueworld/objects/items.py` に記述されている各オブジェクトのクラスに、新しく `self.bbox_size` または `self.bbox_half_extents` といったバウンディングボックスの半長を表す属性（例: `[0.1, 0.1, 0.1]`）を追加する。
   - 特に `is_containable == True` であり、手を離した際に容器との重なり判定が行われるオブジェクトに対して適切なオフセット値を持たせる。
   - 既存の `self.size` プロパティも参考にしつつ、全クラスに対してデフォルト設定や固有設定を追加する。
2. **`_update_grasp` 内でのバウンディングボックス動的化**:
   - `cueworld/base.py` の `_update_grasp` メソッド内で `aabb_min`, `aabb_max` を計算する際、固定の `[1.0, 1.0, 1.0]` ではなく、`self.all_objects[oid]` 側の設定から取得したサイズ（例: `bbox_half_extents`）を使用するように変更する。
   - もし属性が未定義だった場合のフォールバック（例: `[0.1, 0.1, 0.1]`）も用意しておくことで、エラーを防ぐ。
