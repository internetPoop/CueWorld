# 二項の掲げ切り分けテスト

2026-11-05 に合意。ここは切り分けテストの合意メモであり、実装済みの振る舞いの正本ではない。正本は `protocol/dyadic.md` のまま。

このテストで示すのは、親が先に掲げたあいだに、幼児が自分の手を目線帯へ入れて留める動きを、この環境の体と画像で学習できるかである。声と開閉は成功に入れない。学習報酬は、その動きのための密な点だけにする。

## スイッチ

本番の学習とプロトコルの進み方は、既定のままにする。テスト用の変更は、それぞれ別のスイッチの後ろに置く。

| スイッチ | 既定 | オンのとき |
|----------|------|------------|
| 密な報酬 | オフ | 幼児の学習報酬は、下の密な報酬だけ。選好（物を持った点、親の目を見た点）は足さない |
| 掲げで閉じる | オフ | `arm_raise` のヒット率が初めて 0.8 に達した瞬間に、セッションを成功で閉じ、エピソードも終わる。見本が終わっても 0.8 未満なら失敗で閉じる。喃語のオウム返しと持続の真似には入らない |
| 配置モード | 毎回ずらす | 固定、または対象だけ順に変える。`BaseEnv` のモード |
| 観測キー | 全キー | 指定したキーだけを、観測と `observation_space` に残す |
| 行動の種類 | 全行動 | 既存の `infant_action_names`。指定した行動だけを幼児に渡す |

密な報酬がオフのとき、学習報酬は今どおり選好だけにする。密な項は 0 にする。

親のチャネル固定は、今ある `context["parent_channels"]` を使う。新しい口ではない。

## このテストで入れる組み合わせ

- プロトコルは二項に固定する。親始動（`infant_initiative` は既定の偽）。`parent_channels=["arm_raise"]`。
- 密な報酬はオン。掲げで閉じるはオン。
- 幼児の行動は、腰・肩ピッチ・肘だけ。
- 観測は `image` と `joint_angles` だけ。
- 配置モードは、実験のときに選ぶ。3 つとも `BaseEnv` から切れる。

親の掲げ見本（到達待ちと、到達後 90 step の腕振り）は、今のプロトコルのまま動かす。絞るのは幼児の行動と観測、成功と失敗の閉じ方である。

## 見本と失敗

掲げで閉じるがオフのとき（既定）は、今の二項どおりである。見本の途中でもヒット率 0.8 ならモータレーンを開き、見本が終われば `waiting_babble` へ進む。

掲げで閉じるがオンのときは、見本の状態（`performing_parent_cue`）の外へ出ない。

- 手が掲げ位置に届くまで最大 20 step、そのあと 90 step 掲げる。振りは本番のまま（肩ピッチの行動へ振幅 0.35、30 step で 1 往復を 3 回）。
- `hand_height_margin` が初めて 0.8（直近 10 step のうち 8）に達した step で成功にする。見本の途中でもよい。
- 見本が終わっても 0.8 未満なら、その step で失敗にする。下ろしたあとの 5 秒待ちにも、顔離脱にも入らない。
- 見本のあいだ、顔の時計は本番どおり止まる。このテストはその外へ出ないので、顔を外しても閉じない。
- 喃語があってもオウム返しを始めない。声で成功にしない。

## 密な報酬

点が出るのは、見本が始まったときから、最初にヒット率が 0.8 に達するまでである。見本の前は 0。成功したあとも 0。0.8 に届かず見本が終わったあとも 0。

不足は `h = max(0, 帯の下端 − 手の高さ)` である。帯の下端は、エピソード開始時に固定した目線高さ − 0.4 m（`HAND_HEIGHT_TOL`）。手の高さは `hand_link` の world Z。帯に上限は無い。帯に入っていれば `h = 0`。

1 step の点は、`h` の減少分である。0.4 m を 1 とする。帯へ近づくと正、帯から出るほど負。帯の中でさらに上げても 0。合計は「見本が始まった瞬間の `h` − 今の `h`」に収まる。

0.8 に達した呼び出しに、2 を 1 回足す。その後は 0。

この数値は幼児の観測には入れない。言葉には点を付けない。成功の記録は、今どおり `hand_height_margin ≥ 0.8` である。画面の外を向いたまま挙げても、0.8 なら成功で、報酬も入る。見本が無い回は混ぜない。

掲げで閉じるがオフでも、密な報酬の区間は見本の中だけである。見本中に 0.8 へ達すれば +2 を出し、達せずに見本が終わればその先は 0 にする。

## 幼児の行動と観測

行動は次だけにする。

- `torso_joint`
- `shoulder_pitch_joint`
- `elbow_joint`

前進、首、肩ヨー、手首、指、音量、音素は渡さない。高さは肩ピッチと肘で変わる。腰は、親が正面にいないときに見本を画面へ入れるためのものである。

観測は `image` と `joint_angles` である。`joint_angles` の中身は、既存の `infant_action_names` の規則で、残した関節だけになる。腰は sin/cos なので、関節は 4 次元である。

外れるもの: 幼児の声、親の声、親の位置、物の音、物の効果、眠気、触覚、把持、疲労、`is_first`、`is_terminal`。

## 配置モード

`BaseEnv` の 3 つのモードを使う。既定は、今のリセットのままである。

- **毎回ずらす（既定）** — 今のリセットのまま。
- **固定** — 物の種類と位置、幼児の位置、親の位置を、最初のリセットのまま繰り返す。関節だけ毎回 0 に戻す。
- **対象だけ変える** — 位置の固定は同じ。見る／渡す対象だけ、置いてある物のあいだでエピソードごとに順に変える。

二項は物を対象にしない。対象だけ変えるモードは、このテストでは位置を固定したモードと同じになる。最初の学習をどの配置で走らせるかは、ここでは決めない。

## エピソードの終わり

掲げで閉じるスイッチがオンのとき、ヒット率が初めて 0.8 に達した瞬間に、セッションを成功のまま閉じ、その step でエピソードも終わる。持続の真似にも喃語待ちにも入らない。成功フラグは、その瞬間にすでに立っている。

オフのときは、今どおり、モータレーンと声レーンが閉じるまでセッションが続く。

失敗の終わりは、オンのときは見本が終わっても 0.8 未満の step、オフのときは今どおりの失敗経路である。固定プロトコルが終わった step にエピソードが終わる。

## まだ決めないこと

- 3 つの配置モードのうち、最初の学習をどれで走らせるか。
- 指差しから始める共同注意、掲げて見せる共同注意の、密な報酬の中身。
- 音声テスト。親の声の真似と、その報酬。
- オラクルテスト。画像の代わりに、数値で物と親の合図を渡すこと。
