# 受け渡しの切り分けテスト

2026-11-04 に合意。ここは切り分けテストの合意メモであり、実装済みの振る舞いの正本ではない。正本は `protocol/object_giving.md` のまま。

このテストで示すのは、親が床の到達圏に置いた物へ手を伸ばし、開いた手を閉じて拾う動きを、この環境の体と画像で学習できるかである。視線も発話も成功条件に入れない。学習報酬は、その動きのための密な点だけにする。

## スイッチ

本番の学習とプロトコルの進み方は、既定のままにする。テスト用の変更は、それぞれ別のスイッチの後ろに置く。

| スイッチ | 既定 | オンのとき |
|----------|------|------------|
| 密な報酬 | オフ | 幼児の学習報酬は、下の密な報酬だけ。選好（物を持った点、親の目を見た点）は足さない |
| 掴みで閉じる | オフ | 幼児が対象を掴んだ瞬間に、セッションを成功で閉じ、エピソードも終わる。掲げと対象の取り換えはせず、待ちは約 3.4 秒が 2 回で失敗 |
| 親の発話 | オン | オフにする。`parent_utterance=False`。「どうぞ」も「すごい」も言わない |
| 配置モード | 毎回ずらす | 固定、または対象だけ順に変える。`BaseEnv` のモード |
| 観測キー | 全キー | 指定したキーだけを、観測と `observation_space` に残す |
| 行動の種類 | 全行動 | 既存の `infant_action_names`。指定した行動だけを幼児に渡す |

密な報酬がオフのとき、学習報酬は今どおり選好だけにする。密な項は 0 にする。

## このテストで入れる組み合わせ

- プロトコルは受け渡しに固定する。
- 密な報酬はオン。掴みで閉じるはオン。親の発話はオフ。
- 幼児の行動は、腰・首の上下・肩のヨーとピッチ・肘・手首のロールとピッチ・人差し指・`other_fingers`。
- 観測は `image`、`joint_angles`、`tactile`。
- 配置モードは、実験のときに選ぶ。3 つとも `BaseEnv` から切れる。

親の取り寄せ・接近・置きは、今のプロトコルのまま動かす。絞るのは幼児の行動と観測、待ちの梯子、発話である。

## 待ちと失敗

掴みで閉じるがオフのとき（既定）は、今の受け渡しどおりである。約 3.4 秒（34 step）ごとに `handle_timeout(max_retries=3)` の梯子に乗る。1 回目は「どうぞ」を言い直す。2 回目は親が拾い上げて掲げる。3 回目は別の物に取り換える。

掴みで閉じるがオンのときは、掲げと取り換えをしない。約 3.4 秒が 1 回切れたらタイマーだけを戻す（発話オフなので言い直しは空振り）。2 回目の時間切れで失敗する。物は置いた位置のままである。

成功したあとの `reaction`（「すごい」）は、掴みで閉じるがオンのときは通らない。掴んだ瞬間に成功で閉じる。

## 密な報酬

点が出るのは、`waiting_infant` に入ってから、最初の掴み成功までである。置く前は 0。成功したあとも 0。

指標は `e = d × (1 + (1 - cos θ))` である。`d` は掌の中心から対象の中心までの距離、`θ` は掌の前方とその方向との角度。1 m を 1 とする。向いているとき（θ = 0）は `e = d`。真後ろなら `e = 3d`。

1 step の点は、`e` の減少分である。近づいて向くと正、離れると負。合計は「最初の待ちに入った瞬間の `e` − 今の `e`」に収まる。2 回目の待ちでも起点は戻さない。

掴んだ呼び出しに、2 を 1 回足す。その後は 0。

この数値は幼児の観測には入れない。言葉には点を付けない。成功の記録は、今どおり幼児の `held_obj` が対象と一致したときである。

## 幼児の行動と観測

行動は次だけにする。

- `torso_joint`
- `head_tilt_joint`
- `shoulder_yaw_joint`
- `shoulder_pitch_joint`
- `elbow_joint`
- `roll_wrist_joint`
- `pitch_wrist_joint`
- `index_joint`
- `other_fingers`

前進、首の左右、音量、音素は渡さない。拾う動きは腕と手で、物が胸の正面に無いときは腰で到達方向を回す。首の上下は、水平のカメラでは床の置き点が見えないためのものである。首の左右は、腰を回せばカメラも腕も一緒に向くので渡さない。

観測は `image`、`joint_angles`、`tactile` である。`joint_angles` の中身は、既存の `infant_action_names` の規則で、残した関節だけになる。腰と手首ロールは sin/cos なので、関節は 11 次元である。

外れるもの: 幼児の声、親の声、親の位置、物の音、物の効果、眠気、把持フラグ、疲労、`is_first`、`is_terminal`。

## 配置モード

`BaseEnv` の 3 つのモードを使う。既定は、今のリセットのままである。

- **毎回ずらす（既定）** — 今のリセットのまま。
- **固定** — 物の種類と位置、幼児の位置、親の位置を、最初のリセットのまま繰り返す。渡す対象以外の物も、その配置のまま残る。関節だけ毎回 0 に戻す。渡す対象は、その中の 1 つに固定する。
- **対象だけ変える** — 位置の固定は同じ。渡す対象だけ、置いてある物のあいだでエピソードごとに順に変える。

対象の固定には、プロトコルを固定しているときに環境の `target_obj_id` をプロトコルへ渡す、今ある口を使う。このテストはプロトコルを固定する。最初の学習をどの配置で走らせるかは、ここでは決めない。

## エピソードの終わり

掴みで閉じるスイッチがオンのとき、幼児が対象を掴んだ瞬間に、セッションを成功のまま閉じ、その step でエピソードも終わる。`reaction` には入らない。成功フラグは、その瞬間にすでに立っている。

オフのときは、今どおり、称賛の発話が終わってから成功で閉じる。

失敗の終わりは、どちらのスイッチでも、プロトコルが失敗として閉じた step にエピソードが終わる。オンのときは 2 回目の待ち切れ、オフのときは梯子の最後、または拒否である。
