# 見るだけ共同注意の切り分けテスト

2026-11-04 に合意。未実装。ここは切り分けテストの合意メモであり、実装済みの振る舞いの正本ではない。正本は `protocol/joint_attention.md` のまま。

最初に仕様を閉じたのは、共同注意を「見るだけ」から始めるプロトコル単体テストである。音声テスト、オラクルテスト、受け渡し・二項・指差し開始・掲げ開始の報酬表は、ここでは決めない。

このテストで示すのは、合図に応じて対象を約 3 秒見続ける動きを、この環境の体と画像で学習できるかである。学習報酬は、その動きのための密な点だけにする。

## スイッチ

本番の学習とプロトコルの進み方は、既定のままにする。テスト用の変更は、それぞれ別のスイッチの後ろに置く。

| スイッチ | 既定 | オンのとき |
|----------|------|------------|
| 密な報酬 | オフ | 幼児の学習報酬は、下の密な報酬だけ。選好（物を持った点、親の目を見た点）は足さない |
| 合図の固定 | オフ | 時間切れでも合図の種類を変えない |
| 視線成功で閉じる | オフ | 約 3 秒の視線が成立した瞬間に、セッションを成功で閉じ、エピソードも終わる |
| 配置モード | 毎回ずらす | 固定、または対象だけ順に変える。`BaseEnv` のモード |
| 観測キー | 全キー | 指定したキーだけを、観測と `observation_space` に残す。新しい口 |
| 行動の種類 | 全行動 | 既存の `infant_action_names`。指定した行動だけを幼児に渡す |

密な報酬がオフのとき、学習報酬は今どおり選好だけにする。密な項は 0 にする。今の共同注意の `reward_function`（親を見ている量の増え分と、セッション終了時の +1）は、この密な報酬ではない。学習には足さない。

## このテストで入れる組み合わせ

- プロトコルは共同注意に固定し、開始時の合図は見るだけ。
- 密な報酬はオン。合図の固定はオフ。視線成功で閉じるはオン。
- 幼児の行動は、腰・首の左右・首の上下だけ。
- 観測は `image` と `joint_angles` だけ。
- 配置モードは、実験のときに選ぶ。3 つとも `BaseEnv` から切れる。

親の体と発話は、今のプロトコルのまま動かす。絞るのは幼児の行動と観測である。

## 合図

見るだけの合図は、親が幼児から 4.2 m 以内に入ったあとに始まる。部屋はおよそ 5 m × 4 m なので、最初からその範囲にいることが多く、接近は短いことが多い。接近のあいだ、親はまだ対象を向いていない。約 3 秒のカウントも、合図が始まってからである。

合図の固定がオフのとき（既定）は、今の共同注意どおりである。対象を見ないまま、または視線が外れたまま約 5 秒（50 step）たつと、見るだけは 1 回だけ指差しに変わる。親は対象の言葉をもう一度言い、視線のカウントは 0 に戻る。2 回目の時間切れで失敗する。指差しと掲げは、最初から合図を変えず、同じ合図でもう一度言う。

合図の固定がオンのときは、1 回目の時間切れでも合図を変えない。同じ合図のまま、対象の言葉をもう一度言い、視線のカウントを 0 に戻す。2 回目の時間切れで失敗する。チャンスの回数はオフのときと同じで、違うのは 2 回目の合図の強さだけである。

成功したあとに視線が外れてセッションを閉じる処理は、この固定スイッチの対象ではない。

## 密な報酬

点が出るのは、合図の状態（見る、指差す、掲げる）に入ってから、最初の視線成功までである。接近中は 0。成功したあとも 0。

1 step の点は、目の前方と、今の対象の中心との角度の変化である。180°（真後ろ）を 1 とした割合にする。90° から 80° なら +10/180、80° から 90° なら −10/180、同じなら 0。真後ろから正面まで向けた合計の上限は 1。成功の瞬間に、2 を 1 回足す。

起点は、そのセッションで合図が最初に始まった瞬間の角度である。指差しへ上がったあとも、固定スイッチで同じ合図をやり直したあとも、起点は戻さない。近づいてから離れても、角度の合計は「今の角度」と「最初の合図の瞬間の角度」の差に収まる。やり直しで上限の 1 がもう一度入ることはない。

角度は、8° の円錐の確度ではない。円錐の外でも、環境が知っている目の向きと対象の中心から、報酬のためだけに計算する。この数値は幼児の観測には入れない。親の顔へ向けると対象との角度は増えるので、その step は増えた分だけマイナスになる。

言葉には点を付けない。成功の記録は、今どおり最初の 30 step（約 3 秒）の視線で立つ。一言も言わなくても成功である。

## 幼児の行動と観測

行動は `torso_joint`、`head_pan_joint`、`head_tilt_joint` だけにする。前進、腕、指、音量、音素は渡さない。視線の向きは、腰の向きと首の左右・上下で変わる。腕と指は目の向きを変えない。前進は、場所が変わることで対象との角度を変えてしまう。

観測キーを選ぶ口を新しく作る。未指定なら、今どおり全キーを返す。指定したときは、返る辞書と `observation_space` の両方を、そのキーだけにする。指定しなかったキーは 0 で残さない。`is_first` と `is_terminal` も、リストに入れたときだけ残す。エピソードの終了は、観測の外の終了フラグで返す。

このテストのリストは `image` と `joint_angles` である。`joint_angles` の中身は、既存の `infant_action_names` の規則で、残した関節だけになる。腰は sin/cos なので、関節は 4 次元（sin 腰、cos 腰、首の左右、首の上下）である。

外れるもの: 幼児の声、親の声、親の位置、物の音、物の効果、眠気、触覚、把持、疲労、`is_first`、`is_terminal`。

## 配置モード

`BaseEnv` に 3 つのモードを置く。既定は、今のリセットのままである。

今のリセットでは、出す物が毎エピソード抽選され、セルもシャッフルされ、セルの中でも少しずれる。幼児は同じセルの中で少しずれ、親は設定によってセル自体が変わる。関節は毎エピソード 0 に戻る。親が始める共同注意の対象は、幼児が何も見ていなければ、置いてある物からランダムである。

- **毎回ずらす（既定）** — 上の今のリセットのまま。対象の選び方も今のまま。
- **固定** — 物の種類と位置、幼児の位置、親の位置を、最初のリセットのまま繰り返す。見る対象以外の物も、その配置のまま残る。関節だけ毎回 0 に戻す。見る対象は、その中の 1 つに固定する。
- **対象だけ変える** — 位置の固定は同じ。見る対象だけ、置いてある物のあいだでエピソードごとに順に変える。

対象の固定には、プロトコルを固定しているときに環境の `target_obj_id` をプロトコルへ渡す、今ある口を使う。このテストはプロトコルを固定する。

## エピソードの終わり

視線成功で閉じるスイッチがオンのとき、約 3 秒のホールドが成立した瞬間に、セッションを成功のまま閉じ、その step でエピソードも終わる。言葉の待ちには入らない。成功フラグは、その瞬間にすでに立っている。閉じるのは、次のエピソードへ移るときにこの成功が履歴から落ちないようにするためである。

オフのときは、今どおり、親の言葉の残りと、そのあとの約 5 秒の言葉待ちまでセッションが続く。

失敗の終わりは、どちらのスイッチでも同じである。2 回目の時間切れ、または拒否で、プロトコルが失敗として閉じた step にエピソードが終わる。

## まだ決めないこと

- 音声テスト。親の声の真似と、その報酬。
- オラクルテスト。画像の代わりに、数値で物と親の合図を渡すこと。
- 受け渡し、二項、指差しから始める共同注意、掲げて見せる共同注意の、密な報酬の中身。
- 3 つの配置モードのうち、最初の学習をどれで走らせるか。
