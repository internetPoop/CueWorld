# English slides: how a play starts

CueWorld を知らない聴衆向け。16:9 を 1 枚ずつ。タイトルは結論、本文は図だけ。
枠内の英文がスライドに載せる文言。枠の外はレイアウト指示。

共通の前提は、この 2 枚の前に済ませておく。親は見守り・家事・関わりを行き来し、見直しはおよそ 1 秒に 1 回。家事の時計、ペナルティ、温度、弱い腕の数値は載せない。

| フッタ | 「続ける」も選択肢。見守りは離れやすく、家事と進行中の関わりは続きやすい |
